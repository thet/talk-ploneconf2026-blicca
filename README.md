# What’s Up, Mockup? News from Mockup and Patternslib

Mockup, the JavaScript framework behind Plone's Blicca UI (formerly Classic
UI), is evolving rapidly.

Talk @ Plone Conference 2026
Peter Mathis, Johannes Raggam

## About

This talk presents the latest developments in Mockup and Patternslib and shows
how they improve the Plone editing experience and frontend development.

We'll look at the new content browser, the upcoming file manager, and ongoing
work on data binding and the "navigate" event for more dynamic, AJAX-based
interfaces. We'll also cover important changes for developers, including
efforts to modernize frontend tooling and reduce legacy dependencies.

Whether you build Plone add-ons, maintain frontend code, or simply want to know
where Blicca is heading, you'll leave with an overview of the current state of
Mockup and the direction of its future development.

## Running the presentation

To view, start a local webserver and open index.html,
e.g. by running:

```bash
make start
```

(Python 3 required)
